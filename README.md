-RESPOSTAS:
1- Git é um sistema que é instalado dentro da máquina, enqaunto GitHub é uma plataforma online que podemos hospedar os repositórios que nós criamos.

2- Por que assim fica mais fácil de entender exatamente o que foi alterado no projeto.

3- Commit vai relatar quais foram as alterações feitas, explicando com um título e detalhes escritos o que foi alterado, e o push vai jogar as informaçõe que estavam apenas no nosso pc para algo público dentro do github.

4- Você vai utilizar o clone quando for fazer uma revisão de um projeto ou atualização de alguma funcionalidade do código. E o pull quando for feito alguma alteração dentro do Git hub e quiser passar para o código em si no VScode.

5- Gera um conflito, mas o próprio sistema detecta que essas duas alterações foram feitas e impede que uma apague a outra.

6- Ele faz isso por meio de cliques que manipulam o DOM.

7- Por que a equipe pode entender quais as mudanças estão sendo feitas e ver onde estão os erros mais facialmente, além de adicionar novas funções de forma mais segura.
